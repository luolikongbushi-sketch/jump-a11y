# 跳一跳助手

玩微信跳一跳，按精准了能跳过去，按多了飞出去，按少了掉坑里。跟朋友比分数，连着掉了几把都有点上头，就干脆写个东西帮我们按。

思路很简单：**你告诉它从哪跳到哪，它替你完成那一次长按。**

不需要 root，用的是 Android 无障碍的手势注入。

## 怎么用

1. 装上后到 `设置 → 无障碍` 里打开"跳一跳助手"
2. 打开它，点"显示浮层"，然后切回游戏
3. 点浮层上的【选点】，先选**起点**：
   - 手指点一下棋子，点就落在你点的地方
   - 松手后不会马上进下一步，可以直接在屏幕上滑，起点跟着滑，调到准为止
     （手指按在哪儿都行，不用按着那个点 —— 按着会把它挡住）
   - 调好了点【确定】
4. 选**终点**：同样先点一下目标方块，再滑动微调，再【确定】
5. 点【跳】。浮层自动收起，游戏里的棋子就跳过去了

选点分成"粗选 + 微调"两步，是因为手指比目标大，一次点准很难。粗选靠眼睛，微调靠滑动。

## 主题

自带浅色和深色两套，在主界面里切换，选完记住。深色跟着系统走还是手动选都行。

## 按不准怎么办

不同手机、不同分辨率下，"按多久跳多远"这个换算比例是不一样的，所以有个【校准】：

> 点【校准】→ 选起点和终点 → 点【跳】跳一次 → 点一下棋子**实际停在哪**

程序会拿你这次实际跳出来的距离跟目标的距离一比，直接算出你这台机器真正的系数，存下来，之后就一直准了。做一次就行。

也可以手动改系数，在主界面里。

## 它不做什么

写的时候就刻意限制在这个范围里：

- 不联网（APK 里连 `INTERNET` 权限都没有，想联网也联不了）
- 不截屏、不读屏幕内容（`canRetrieveWindowContent` 关着，也没用截图 API）
- 不要 root，不执行 shell
- 没有埋点、没有统计、没有自启

无障碍权限本身是个敏感权限，所以这几条是明确的边界，不是"暂时没做"。

## 编译

需要 JDK 17+、Android SDK（compileSdk 34）。

```bash
# 在项目根目录放一个 local.properties，指向你的 SDK
echo "sdk.dir=/path/to/android-sdk" > local.properties

./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

> 注意：`settings.gradle` 里仓库顺序是阿里云镜像在前、官方在后。国内网络下这个顺序
> 明显更快，官方的 google maven 经常连不上会让构建干等。国外的话把顺序调回来就行。

## 环境

- minSdk 24（Android 7.0）

- Kotlin

## 图标

`make-icons.ps1` 是生成图标用的：拿一张正方形原图，只加圆角，输出各个分辨率。
想换图标就改脚本里的 `$Src` 指向新图，重新跑一遍。原图得是正方形的。
